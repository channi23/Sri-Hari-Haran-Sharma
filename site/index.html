Agent systemFeatured

Sizuka

An AI talent scouting agent that turns a job description into a live candidate discovery and outreach workflow.

Sizuka extracts hiring criteria, discovers developers through GitHub and Hacker News, analyses profiles, scores candidate fit with an LLM, generates personalised outreach and follows email replies. NestJS, BullMQ and Redis coordinate the workflow while a Python agent, PostgreSQL and a React dashboard handle intelligence, state and visibility.
